Path to Astra: Critical cyber threshold, delayed RL, layered refusals

OpenAI says Astra can find previously unknown flaws and develop exploits across many hardened systems without step-by-step human guidance. Evaluations include ExploitBench at 100%, an internal June–August V8 set where it used two zero-days now being disclosed, and expert-led browser/OS exploit chains. Large frontier RL was paused after the Hugging Face incident and restarted 28 Aug under tighter isolation. Production advanced-cyber workflows stay restricted at launch.

Claude Fable 5.1 generally available; Mythos 5.1 stays trusted-access

Same weights, two safeguard stacks. Fable 5.1 is on Claude.ai, Claude Code and cloud marketplaces; Anthropic claims ~25% lower typical token cost via cheaper cache reads, fewer cyber false positives, and permission to discover vulnerabilities but not write exploits. Mythos 5.1 is priced from $10 / $50 per million tokens and limited to vetted cyberdefenders and a life-sciences verification beta. Enterprise Frontier Safeguards (customer-held data) are promised later this fall.
